# ADR-0048：压缩会话与索引选择

状态：Accepted

## 问题

Codex Home 可能同时保留根目录和 `sqlite/` 中的 state 数据库，并将会话压缩为 `.jsonl.zst`。仅按未压缩文件数量比较数据库会偏向旧索引。Provider 扫描当前只读取 `.jsonl`；将未扫描路径对应的 SQLite 行直接改为目标 Provider 会造成文件和索引不一致。

## 决定

默认数据库候选的计数包含 `.jsonl.zst`，同一目录下同名压缩与未压缩文件视为一个会话。该比较仍是启发式，显式 SQLite Home 的优先级和缺库失败规则不变，不能声称自动识别必然正确。

普通 Provider 同步不解压、修改或推断压缩会话的首行。如果 SQLite 行有非空 rollout 路径，而本次扫描没有该路径的首行事实，则不更改该行，使用既有 `association-unknown` 和 partial 结果报告。此规则同样适用于缺失、越界或指向其他未扫描文件的路径；其他文件有同样 ID 不能证明这条路径已经对齐。没有 rollout 路径的旧索引保留原兼容行为。

## 边界

不改变 Sync 只读取首行、备份顺序、Plan/Apply 重验及成功写入语义。不新增解压依赖，也不重写历史模型或修改 `rollout_path`。不能将跳过的压缩会话当作已同步；是否支持其安全写入及分页索引仍需另行设计和验证。
